## 1. What I Learned

Through this assignment, I learned how to use PL/SQL `GOTO` statements and labels to control the flow of a program. I also learned why `GOTO` has restrictions and how the same logic can be rewritten using normal PL/SQL control structures such as `IF...ELSE`.

I also learned how to create and use stored functions in Oracle. The functions helped me calculate annual salary, years of service, tax, and department names. I learned that functions can also be called directly inside SQL `SELECT` statements.

## 2. Challenges

One challenge was understanding the correct use of `GOTO` and avoiding illegal jumps between different PL/SQL blocks. Another challenge was testing stored functions and making sure they returned the expected values.

Using SQL Developer helped me understand how to create functions, execute SQL statements, and check the output.

## 3. What I Would Improve

I would improve the assignment by adding more validation and exception handling to the functions. I would also use more test cases, including invalid employee IDs and different salary values.

## 4. Conclusion

This assignment improved my understanding of PL/SQL program control, stored functions, exception handling, and using functions within SQL queries. It also gave me more practical experience working with Oracle Database and SQL Developer.
